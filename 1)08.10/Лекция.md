# Введение в ADO.NET: архитектура и базовые операции

ADO.NET — это базовая технология платформы .NET, предназначенная для прямого взаимодействия с реляционными базами данных (Microsoft SQL Server, PostgreSQL, SQLite, MySQL и другими). Она предоставляет низкоуровневый доступ к СУБД, гарантируя максимальный контроль над SQL-запросами, сетевыми вызовами и ресурсами сервера.

---

## Архитектура ADO.NET: два режима работы

Вся работа с данными в ADO.NET разделена на два фундаментальных подхода:

1. **Подключенный уровень (Connected Mode):** программа держит непрерывное сетевое соединение с СУБД, считывает данные на лету потоком и немедленно освобождает ресурсы.
2. **Отключенный уровень (Disconnected Mode):** данные один раз выгружаются в оперативную память приложения, соединение с базой сразу закрывается, а пользователь работает с локальной копией (кэшем).

### Сравнение режимов работы

| Характеристика     | Подключенный режим (Connected)                 | Отключенный режим (Disconnected)           |
| ------------------ | ---------------------------------------------- | ------------------------------------------ |
| Связь с базой      | Постоянное открытое соединение                 | Соединение закрывается сразу после выборки |
| Потребление ОЗУ    | Минимальное (данные передаются потоком)        | Зависит от объема загруженных данных       |
| Скорость выборки   | Максимальная                                   | Затраты на построение локальных структур   |
| Направление обхода | Только вперед (Forward-only)                   | Вперед и назад, по индексам и связям       |
| Ключевые классы    | `SqlConnection`, `SqlCommand`, `SqlDataReader` | `DataSet`, `DataTable`, `SqlDataAdapter`   |

---

## Пять базовых классов ADO.NET

Для работы с Microsoft SQL Server используется библиотека `Microsoft.Data.SqlClient`. В ней определены основные строительные блоки:

- **`SqlConnection`** — управляет физическим сеансом связи с СУБД.
- **`SqlCommand`** — хранит текст SQL-инструкции, параметры и ссылку на активное подключение.
- **`SqlDataReader`** — обеспечивает быстрое, однонаправленное чтение строк из результата запроса.
- **`SqlParameter`** — передает переменные в команду в строго типизированном виде, исключая SQL-инъекции.
- **`SqlDataAdapter`** — служит мостом между базой и объектами в памяти (`DataSet`/`DataTable`).

---

## Подключение к базе данных: класс SqlConnection

Для открытия сессии необходима строка подключения (_Connection String_). Она сообщает драйверу сетевой адрес сервера, имя базы данных и способ авторизации.

### Пример строки подключения

- **Windows-аутентификация (текущий пользователь ОС):**
  `Server=localhost;Database=ShopDb;Integrated Security=True;TrustServerCertificate=True;`
- **SQL-аутентификация (по логину и паролю):**
  `Server=localhost;Database=ShopDb;User Id=sa;Password=Secret123!;TrustServerCertificate=True;`

### Управление ресурсами через `using`

Подключения задействуют ограниченные ресурсы операционной системы. Конструкция `using` гарантирует автоматический вызов метода `Dispose()`, который возвращает сокет в пул соединений даже в случае аварийной ошибки.

```csharp
using System;
using Microsoft.Data.SqlClient;

class Program
{
    static void Main()
    {
        string connStr = "Server=localhost;Database=ShopDb;Integrated Security=True;TrustServerCertificate=True;";

        using (SqlConnection connection = new SqlConnection(connStr))
        {
            connection.Open();
            Console.WriteLine($"Соединение открыто. Статус: {connection.State}");
        } // Здесь соединение гарантированно закрывается
    }
}
```

## Выполнение запросов: класс SqlCommand

Объект `SqlCommand` отправляет SQL-инструкции на сервер. В зависимости от типа команды вызывается один из трех методов:

1. **`ExecuteNonQuery()`** — выполняет инструкции `INSERT`, `UPDATE`, `DELETE`, `CREATE TABLE`. Возвращает целое число — количество измененных строк.
2. **`ExecuteScalar()`** — выполняет запросы, возвращающие единственное значение (агрегатные функции `COUNT`, `SUM`, `MAX`). Возвращает объект `object` (первое поле первой строки).
3. **`ExecuteReader()`** — выполняет запрос `SELECT` и возвращает поток строк для чтения.

### Пример: вставка строки и подсчет записей

```csharp
using System;
using Microsoft.Data.SqlClient;

class Program
{
    static void Main()
    {
        string connStr = "Server=localhost;Database=ShopDb;Integrated Security=True;TrustServerCertificate=True;";

        using (SqlConnection connection = new SqlConnection(connStr))
        {
            connection.Open();

            // 1. Вставка новой строки
            string insertQuery = "INSERT INTO Products (Title, Price) VALUES ('Механическая клавиатура', 3500);";
            using (SqlCommand insertCmd = new SqlCommand(insertQuery, connection))
            {
                int rows = insertCmd.ExecuteNonQuery();
                Console.WriteLine($"Строк добавлено: {rows}");
            }

            // 2. Получение скалярного значения
            string countQuery = "SELECT COUNT(*) FROM Products;";
            using (SqlCommand countCmd = new SqlCommand(countQuery, connection))
            {
                int total = Convert.ToInt32(countCmd.ExecuteScalar());
                Console.WriteLine($"Всего товаров в таблице: {total}");
            }
        }
    }
}
```

## Потоковое чтение: класс SqlDataReader

`SqlDataReader` не загружает всю таблицу в память целиком, а читает ее построчно из входящего сетевого буфера.

- Метод `reader.Read()` перемещает указатель к следующей строке. Он возвращает `true`, если строка существует, и `false`, когда данные закончились.
- Доступ к полям текущей строки осуществляется либо по индексам (`reader.GetInt32(0)`), либо по именам колонок (`reader["Title"]`).

```csharp
using System;
using Microsoft.Data.SqlClient;

class Program
{
    static void Main()
    {
        string connStr = "Server=localhost;Database=ShopDb;Integrated Security=True;TrustServerCertificate=True;";
        string selectQuery = "SELECT Id, Title, Price FROM Products;";

        using (SqlConnection connection = new SqlConnection(connStr))
        {
            connection.Open();

            using (SqlCommand command = new SqlCommand(selectQuery, connection))
            using (SqlDataReader reader = command.ExecuteReader())
            {
                if (reader.HasRows)
                {
                    while (reader.Read())
                    {
                        int id = reader.GetInt32(0);
                        string title = reader.GetString(1);
                        decimal price = reader.GetDecimal(2);

                        Console.WriteLine($"[#{id}] {title} — {price:C}");
                    }
                }
                else
                {
                    Console.WriteLine("Таблица пуста.");
                }
            }
        }
    }
}
```

## Безопасность: параметризованные запросы

Конкатенация строк при формировании SQL-запроса (`"WHERE Title = '" + userInput + "'"`):

1. Открывает уязвимость перед **SQL-инъекциями** (злоумышленник может повредить или похитить данные).
2. Вызывает ошибки синтаксиса, если в тексте пользователя есть апострофы или кавычки.
3. Мешает серверу эффективно кэшировать планы выполнения.

Правильный подход — использование параметров с префиксом `@`.

```csharp
using System;
using System.Data;
using Microsoft.Data.SqlClient;

class Program
{
    static void Main()
    {
        string connStr = "Server=localhost;Database=ShopDb;Integrated Security=True;TrustServerCertificate=True;";

        string userInputTitle = "Клавиатура";
        decimal userInputMaxPrice = 5000m;

        // В запросе используются именованные метки-плейсхолдеры
        string safeQuery = "SELECT Id, Title, Price FROM Products WHERE Title = @Title AND Price <= @Price;";

        using (SqlConnection connection = new SqlConnection(connStr))
        {
            connection.Open();

            using (SqlCommand command = new SqlCommand(safeQuery, connection))
            {
                // Явное добавление строго типизированных параметров
                command.Parameters.Add("@Title", SqlDbType.NVarChar, 100).Value = userInputTitle;
                command.Parameters.Add("@Price", SqlDbType.Decimal).Value = userInputMaxPrice;

                using (SqlDataReader reader = command.ExecuteReader())
                {
                    while (reader.Read())
                    {
                        Console.WriteLine($"Найден: {reader["Title"]} за {reader["Price"]}");
                    }
                }
            }
        }
    }
}
```
